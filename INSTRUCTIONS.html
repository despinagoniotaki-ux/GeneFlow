GeneFlow MVP

Gene-Therapy Compliance · Change-Impact · Evidence-Traceability Platform

⚙️ Prerequisites

GeneFlow requires Python 3.9 or later. Confirm your version before proceeding:

python3 --version

Install the two required packages (Flask for the web UI, pytest for the test suite):

pip install flask pytest
💡 Tip — virtual environment Using a virtual environment keeps your global Python install clean: python3 -m venv .venv && source .venv/bin/activate, then run the pip install above inside it.

🚀 Quick Start (two commands)

  1. Navigate to the project folder 
    cd ~/Downloads/GeneFlow_MVP
  2. Start the web server 
    python3 app/frontend/server.py
    You should see: 
    [GeneFlow] Documents folder : /Users/…/GeneFlow_MVP/documents
[GeneFlow] Starting server  : http://127.0.0.1:5000
  3. Open the dashboard
    Go to http://127.0.0.1:5000 in your browser, then click “⚡ Run Demo (pre-loaded package)” to run the full compliance pipeline against all 10 pre-loaded mock documents.

🖥️ Dashboard — Three Screens

📤 Package Upload

Drop in your own .txt or .pdf compliance documents and click “▶ Run Compliance Analysis”. The pipeline will ingest, extract claims, detect version changes, resolve SOP dependencies, and return a live findings report. Use “⚡ Run Demo” to analyse the 10 pre-loaded mock documents instantly.

🔍 Findings Dashboard

Shows headline statistics (total alerts, CRITICAL / HIGH / MEDIUM counts, documents loaded, claims extracted) and an Executive Summary. Below, every alert is rendered as a priority card sorted by severity, each displaying:

  • Alert type and severity badge
  • Plain-English description of the discrepancy
  • Source document tags
  • A tailored Reconciliation Action prompt
  • Per-finding Mark Resolved and Escalate buttons

🔬 Evidence Inspector

Lists every atomic evidence claim extracted from the documents, showing the source document ID, parameter type, value, and the raw verbatim quote from the source text. The Human-in-the-Loop action bar lets you:

  • ✅ Approve All Reconciliations — log bulk acknowledgement
  • ⚠️ Escalate Critical to QA — flag for QA team follow-up
  • 📥 Export Report JSON — download the full impact report as a .json file

📄 Using Your Own Documents

Plain-text format

Documents should follow this structured header format for best extraction results:

Document: <title>
ID: <unique-id>
Version: <version>
Date: YYYY-MM-DD
Author: <name>

Section: <section name>
Content: <free text…>

Section: <another section>
Content: <free text…>

Any plain .txt file will still be ingested — unrecognised lines are treated as section body text.

PDF documents

PDF support requires PyMuPDF. Install it with:

pip install PyMuPDF
💡 Uploading via the UI Use the Package Upload screen to drag-and-drop any combination of .txt and .pdf files. The pipeline runs automatically on upload.

📥 Exporting Results

From the Evidence Inspector screen, click “📥 Export Report JSON” to download the full impact report. You can also call the API directly:

curl http://127.0.0.1:5000/report

This returns the most recent pipeline result as a JSON object conforming to schemas/impact_report.json.

🔒 Security

⚠️ Local use only The Flask server binds exclusively to 127.0.0.1 (loopback). It is not reachable from other machines on your network. Do not change the host to 0.0.0.0 without adding authentication, as the upload endpoint accepts arbitrary files.

The maximum upload size is capped at 32 MB per request.

🔧 Troubleshooting

SymptomLikely causeFix
ModuleNotFoundError: flask Flask not installed in current environment Run pip install flask (activate your venv first if using one)
Address already in use Port 5000 is occupied Kill the process: lsof -ti:5000 | xargs kill
Demo returns 0 alerts documents/ folder not found Run the server from inside GeneFlow_MVP/, not a subdirectory
PDF shows no claims PyMuPDF not installed pip install PyMuPDF
Pytest import errors Running pytest from wrong directory Always run pytest tests/ -v from GeneFlow_MVP/

♻️ Re-bootstrapping

To reset the project to a clean state (e.g. after editing mock documents), re-run the bootstrap script from the workspace root:

python3 bootstrap_geneflow.py
⚠️ Warning — this overwrites all files Running the bootstrap script will overwrite every file in ~/Downloads/GeneFlow_MVP/, including any documents you have added. Back up custom documents first.
